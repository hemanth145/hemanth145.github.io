# hemanth145.github.io

Personal portfolio site for Sai Hemanth Babu Sunkari, built with React + Vite.

Live at: https://hemanth145.github.io

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Pushes to `main` automatically build and deploy to GitHub Pages via the workflow in
`.github/workflows/deploy.yml`. In the repo settings, under **Pages**, set the source to
**GitHub Actions**.
